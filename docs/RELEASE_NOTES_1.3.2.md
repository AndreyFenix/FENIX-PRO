# FENIX PRO 1.3.2

- Responsive layout tiers for wide, medium and compact windows.
- Icon-only navigation at narrow window widths.
- Compact two-column dashboard statistics.
- Shared dark FENIX dialog service for application and startup prompts.
- Fallback from disconnected download drives to the user's Videos/FENIX folder.
- Default update repository: AndreyFenix/FENIX-PRO.

## Update availability
The app needs a published GitHub Release with FENIX-PRO-x64.exe and FENIX-PRO-x64.exe.sha256. There is no binary update until those assets are attached to a Release.

## QA status
Static source checks only; Windows build and runtime UI testing are still required.
