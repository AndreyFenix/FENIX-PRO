# Brand asset notes

The brand glyphs in `assets/brand` and the application resource folder are sourced from the Simple Icons project: https://github.com/simple-icons/simple-icons .

The Simple Icons repository describes the project as SVG icons for popular brands and is marked CC0-1.0. Its disclaimer states that individual icon licensing may differ and asks users to check the applicable icon license. Brand names and marks remain trademarks of their respective owners; their brand usage guidelines still apply.

FENIX is not affiliated with or endorsed by YouTube, TikTok, Instagram, Facebook, X, Twitch, Vimeo or SoundCloud. These SVG assets are embedded in the application package so the application does not need to fetch logo files at runtime.
