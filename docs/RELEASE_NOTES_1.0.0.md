# FENIX PRO 1.0.0 — First public release

FENIX PRO 1.0.0 is intended as the project's first public Windows release.

## Included

- Dark WPF interface with adaptive wide, regular and compact layouts.
- Ukrainian, Russian and English interface languages.
- Adjustable text size (90–130%).
- Link analysis and metadata preview where supported by the source.
- MP4, MKV and WebM video output.
- MP3, M4A, FLAC, WAV, Opus and AAC audio output.
- Download profiles, queue management, concurrency and speed limits.
- Media library, task history, search and sorting.
- Duplicate protection, settings export/import and mini mode.
- GitHub Releases update checks and SHA-256 verification.

## Notes

- Metadata and alternate audio tracks depend on information supplied by each source.
- Some sites and formats may not be supported.
- The updater requires a published GitHub Release with `FENIX-PRO-x64.exe` and `FENIX-PRO-x64.exe.sha256`.
- Windows 10/11 x64 is required.

Only download material you own or are authorized to save. FENIX PRO does not bypass DRM or access restrictions.
